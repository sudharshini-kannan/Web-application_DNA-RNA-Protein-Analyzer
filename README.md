# 🧬 DNA → RNA → Protein Analyzer

An interactive bioinformatics web application built with Python and Streamlit for DNA sequence analysis, transcription, translation, and protein analysis.

## ✨ Features

* **DNA Sequence Analysis** — Validate DNA sequences and calculate sequence statistics.
* **DNA to RNA Transcription** — Transcribe coding and template DNA strands.
* **Reading Frames** — Explore six reading frames.
* **ORF Detection** — Identify open reading frames.
* **Protein Translation** — Translate RNA codons into amino acid sequences.
* **Codon Usage Analysis** — Examine codon frequencies.
* **Sequence Comparison** — Compare DNA sequences.
* **GC Window Analysis** — Explore GC content across sequence windows.
* **Interactive Interface** — Explore results through a Streamlit application.
* **Automated Tests** — Run bioinformatics validation tests.

## 🛠️ Technologies

* Python
* Streamlit
* Matplotlib
* Bioinformatics algorithms
* Pytest

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sudharshini-kannan/Web-application_DNA-RNA-Protein-Analyzer.git
cd Web-application_DNA-RNA-Protein-Analyzer
```

Install the required Python packages:

```bash
pip install streamlit matplotlib pytest
```

Start the application:

```bash
streamlit run streamlit_app.py
```

## 🧪 Tests

Run the test suite with:

```bash
pytest -q
```
